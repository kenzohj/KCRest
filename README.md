# 🎬 KCRest - KCiné's REST API (2023)

**🇫🇷 Français | [🇬🇧 English below](#-english-version-)**  

---

## 📌 À propos du projet

**KCRest** est une API REST développée pour l'application mobile [**KCiné**](https://github.com/kenzohj/KCine). Ce projet a été réalisé en **2ᵉ année de BUT Informatique** par :  

- [Corentin Bonjour](https://github.com/corentinbjr)  
- [Kenzo Hambli](https://github.com/KenzoHJ)

L'API permet d'authentifier les utilisateurs et de récupérer la liste des cinémas à proximité ainsi que les films disponibles et leurs horaires.

### 📌 Remarques importantes  

- Les **films sont fictifs**, car nous n'avons pas eu accès à des API fournissant des films réellement disponibles.  
- Les **cinémas proviennent d’un fichier JSON public** contenant leurs coordonnées GPS.  
- Les mots de passe des utilisateurs sont **hashés avec un salt** pour garantir la sécurité des données.  

---

## 🔧 Technologies utilisées  

- **Langage :** Java 17  
- **Framework :** [Spring Boot](https://spring.io/projects/spring-boot) 
- **Base de données :** [SQLite (via SQLite-JDBC)](https://www.sqlite.org/)
- **ORM :** [Hibernate](https://hibernate.org/)
- **Parser :** [FasterXML](https://github.com/FasterXML)  
- **Sécurité :** [Hashing des mots de passe avec un salt](https://fr.wikipedia.org/wiki/Salage_(cryptographie))

---

## 📂 Endpoints principaux

📍🎥 **Récupération des cinémas & films →** `/api`

🎟 **Gestion des réservations →** `/article`

🔐 **Gestion des utilisateurs →** `/user`

> **💡 Note :** Une interface web auto-générée par Swagger est disponible à [http://localhost:9090/api.html](http://localhost:9090/api.html) listant les endpoints de manière plus détaillée.

## 🇬🇧 English Version  

### 📖 About the project  

**KCRest** is a REST API developed for the **KCiné** mobile application. This project was built during our **2nd year of a Computer Science Bachelor’s program (BUT Informatique)** by:  

- [Corentin Bonjour](https://github.com/corentinbjr)  
- [Kenzo Hambli](https://github.com/KenzoHJ)

The API allows to authenticate users and retrieve nearby cinemas and available movies with their showtimes.

### 📌 Important Notes  

- **Movies are fictional**, as we couldn't access APIs providing real-time movie data.  
- **Cinemas are sourced from a public JSON file** with their GPS coordinates.  
- User passwords are **hashed with a salt** for enhanced security.

- **ORM:** [Hibernate](https://hibernate.org/)  
- **Parser:** [FasterXML](https://github.com/FasterXML)    
- **Security:** [Password hashing with a salt](https://en.wikipedia.org/wiki/Salt_(cryptography))
